# Smart-Drug-Recommendation-System-for-Clinical-decision-support

Drug recommendation in healthcare is a complex task that depends on patient symptoms, age, gender, and disease conditions. Traditional methods rely on manual analysis and physician experience, which can be time-consuming and inconsistent.
Many existing machine learning models struggle to handle unstructured symptom text and fail to capture complex relationships between patient data and drug prescriptions. Some deep learning models also treat all symptoms equally, ignoring the importance of critical symptoms, which affects accuracy and reliability.
To address these issues, this project proposes a drug recommendation system that uses TF-IDF to represent symptom text, a Deep Neural Network (DNN) as a base model, and an Attention-based DNN to focus on important symptoms. The goal is to improve accuracy, generalization, and interpretability while maintaining computational efficiency.
